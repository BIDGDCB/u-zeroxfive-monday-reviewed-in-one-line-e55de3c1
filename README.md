Entry for the make.fun competition
`u-zeroxfive-monday-reviewed-in-one-line-e55de3c1`.

`main.ts` writes a single one-line review of Monday — the whole day, rated
in one breath — to `/output/entry.txt`. The line is validated before it is
written: 1 to 200 characters, a single line, not only white space.

The entry line:

> Monday arrived like a software update nobody asked for: slow, unavoidable, and it deleted my weekend. One star. Would not install again.
